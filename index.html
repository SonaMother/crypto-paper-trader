How this works

1. Paper buys

Each token was bought for $1 of paper money at the live market price when the portfolio was initialized. No real funds are involved.

2. Live price feeds

Prices are fetched from CoinGecko and GeckoTerminal every hour by a GitHub Actions cron job. Each update is a git commit, so history is preserved.

3. Open & clone

This dashboard is a static site hosted on GitHub Pages. Clone the repo and run python scripts/update_portfolio.py to refresh locally.
