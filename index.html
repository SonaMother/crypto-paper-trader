How this works

1. Paper buys

Each token was bought for $1 of paper money at the live market price when the portfolio was initialized. No real funds are involved. zAI's 4 picks vs gAi's 2 picks.

2. Live price feeds

The dashboard fetches live prices directly from CoinGecko's public API every 60 seconds while you have the page open. No server, no cron needed for live prices.

3. Open & clone

This dashboard is a static site hosted on GitHub Pages. Clone the repo and run python scripts/update_portfolio.py to commit fresh snapshots to the price history.
